# Aditya Bhadauria · Portfolio

Personal site. One scrolling page: hello, about, agents/RAG/evals, a computer vision case study, numbers, experience, toolkit, work and contact.

- `index.html` holds all the content.
- `src/main.js` runs the scroll animation (faces, quips, halo, chips).
- `src/style.css` holds the styles.
- `public/face/` has the face frames, `public/Resume_AdityaBhadauria.pdf` is the resume.

```bash
npm install
npm run dev
```
